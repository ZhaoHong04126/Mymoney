# 🍯 快樂記帳本 (Mymoney)

> **今天也要溫柔地打理生活 ✨**  
> 一款採用溫暖琥珀奶油色系設計的原生 Android 個人記帳與多帳戶資產管理 App（桌面名稱：**生活記帳本**）。全程本機離線儲存、零廣告、免註冊、無網路權限需求，讓日常理財回歸單純與安心。

---

## ✨ 功能特色

### 📒 收支明細與月度總覽
- **月度收支儀表板**：一眼掌握本月總支出、本月收入、本月結餘，以及截至當月的總淨資產（點擊可直接跳轉帳戶總覽）。
- **多維度快速篩選**：支援依交易類型（全部／支出／收入／轉帳）與指定帳戶即時篩選帳目。
- **每日分組清單**：依日期由新至舊自動分組並小計當日收支，點擊任一筆紀錄即可快速修改或刪除。
- **直覺月份切換**：頂部切換器可自由瀏覽前後月份，點擊月份標題即可一鍵回到本月。

### 🔒 歷史月份霧面鎖定
- 早於首次使用月份的歷史帳本預設套用**霧面毛玻璃鎖定遮罩**（Android 12+ 支援原生 `RenderEffect` 模糊效果），避免日常滑動時誤改舊帳。
- 需要補記過往帳目時，只需點擊「開啟帳本」確認即可解除該月份鎖定。

### 🎯 月度預算進度追蹤
- 自由設定每月總預算（預設 `NT$10,000`，內建 `$5,000`、`$10,000`、`$15,000`、`$20,000` 快速選額標籤）。
- **三段式溫柔提醒**：依支出佔比自動切換進度條色調與狀態標籤：
  - **未滿 80%**：`安心花費中 ✨`
  - **80% ～ 99%**：`接近預算上限`
  - **100% 以上**：`已超支提醒 🐾`（即時顯示超支金額）

### 🧮 快速記帳與內建計算機
- 底部導覽列中央配置凸起式 **「＋ 記一筆」** 按鈕，隨時一鍵開啟記帳抽屜。
- 支援 **支出**、**收入**、**帳戶間轉帳** 三種記帳模式。
- 內建 `4 × 5` 記帳專用計算機鍵盤，支援 `+`、`−`、`×`、`÷` 四則運算與小數即時試算，上方同步顯示算式預覽。
- 新增收支時可一併勾選「同時加入每月固定週期收支清單」。

### 🍩 互動式圓環統計與分類排行
- 原生自繪 `DonutChartView` 互動式甜甜圈圖表，支援**支出分類佔比**與**收入分類佔比**切換。
- 點擊圓環扇區或下方分類排行卡片，圖表中央即時顯示該分類總額與百分比，並可展開查看該分類下的逐筆消費明細。

### 👛 多帳戶與淨資產管理
- 支援四大帳戶類型分組管理：
  - 💵 **現金錢包**（預設：隨身現金）
  - 🏦 **銀行存款**（預設：郵局帳戶）
  - 📱 **電子支付 / 票卡**（預設：LINE Pay）
  - 💳 **信用卡 / 負債**（預設：日常信用卡）
- 依據各帳戶初始餘額與歷月收支、轉帳紀錄，自動彙算**總資產**、**信用卡／負債**與**淨資產總額**。
- 支援新增、編輯、刪除帳戶（內建至少保留一組帳戶的防呆機制）與快捷帳戶間轉帳。

### 🗓️ 固定週期收支提醒
- 集中管理房租、串流訂閱、水電費或固定月薪（可設定每月 1～31 日固定入帳日、收支類型、分類與對應帳戶）。
- 當月若有尚未入帳的週期項目，首頁會自動浮現提醒橫幅，點擊 **「一鍵入帳」** 即可批次寫入本月帳目。

### 🏷️ 自訂收支分類管理
- 預設內建 **8 種支出分類**與 **4 種收入分類**，並提供 23 款精選 Emoji 圖示自由新增、重新命名或刪除分類。
- 內建系統保留分類（「其他支出 ✨」、「其他收入 🌟」）防誤刪保護，並支援一鍵還原系統預設分類。

### 📦 資料備份匯出與匯入
- 採用 Android 系統級 Storage Access Framework (SAF) 讀寫檔案，無須授予敏感儲存權限。
- **匯出 CSV**：自動加上 UTF-8 BOM 檔頭（檔名預設為 `快樂記帳本_備份資料_YYYY-MM.csv`），使用 Excel 直接開啟不亂碼。
- **匯入 CSV / JSON**：支援匯入 `.csv` 交易明細、`.json` 交易陣列（附加至現有帳本），或完整 `.json` 帳本備份檔（還原全部設定與紀錄）。

## 🚀 快速開始

### 環境需求
- **Android Studio**（建議使用支援 AGP 9.5 / SDK 37 之最新版本）
- **JDK 17** 以上版本
- **Android SDK Platform 37**

### 安裝與執行步驟

1. **取得專案原始碼**
   ```bash
   git clone https://github.com/ZhaoHong04126/Mymoney.git
   cd Mymoney
   ```

2. **使用 Android Studio 開啟**
   - 開啟 Android Studio，選擇 **Open** 並選取專案根目錄。
   - 等待 Gradle Sync 同步完成後，連接實體手機或啟動 Android 模擬器（API 26+），點擊 **Run (`Shift + F10`)** 即可安裝執行。

3. **使用指令列建置 Debug APK**
   - **Windows (PowerShell / CMD)**：
     ```powershell
     .\gradlew.bat assembleDebug
     ```
   - **macOS / Linux**：
     ```bash
     ./gradlew assembleDebug
     ```
   - 建置完成後，APK 檔案會產生於 `app/build/outputs/apk/debug/app-debug.apk`。

## 📄 匯入與匯出檔案格式說明

### CSV 格式（匯出與匯入通用）
第一列為標題列，欄位順序如下：

```csv
日期,類型,分類,金額,帳戶,轉入帳戶,備註
2026-11-24,支出,餐飲美食,135,LINE Pay,,"午餐便當"
2026-11-24,轉帳,帳戶轉帳,3000,郵局帳戶,隨身現金,"提領生活費"
```

- **日期**：`YYYY-MM-DD` 格式
- **類型**：`支出`、`收入` 或 `轉帳`
- **金額**：大於 `0` 之正整數

### JSON 格式
支援以下兩種結構匯入：
1. **完整帳本備份物件（覆蓋還原）**：包含 `monthlyBudget`、`firstLoginMonth`、`unlockedMonths`、`accounts`、`categories`、`recurring` 與 `transactions` 欄位之完整 JSON 物件。
2. **純交易紀錄陣列（附加匯入）**：由交易物件（含 `type`、`categoryId`、`accountId`、`toAccountId`、`amount`、`date`、`note`）組成的 JSON Array `[...]`。

## 🔒 隱私聲明

**快樂記帳本**未申請 `INTERNET` 網路權限，所有帳目、帳戶餘額與預算設定皆 100% 儲存在您的裝置本機空間中，不會上傳至任何外部伺服器。更換手機或重置裝置前，建議至 **「⚙️ 更多 → 📦 資料匯出 / 匯入」** 手動匯出備份檔案留存。
